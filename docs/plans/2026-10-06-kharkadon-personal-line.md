# Kharkadon Personal Skill Line Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking. Work sequentially in the existing workspace; this root is not a Git repository.

**Goal:** Replace Kharkadon's eight personal skills and give Stand With Your Overlord a temporary Perfect Vigour aura.

**Architecture:** Extend the existing lord generator and its selftest, reusing the established TSV/RPFM import flow. Clone native ability and effect bindings, adding only the unit sets needed to target his elite infantry and four bodyguards. Keep everything in the existing lords pack, with no campaign or battle Lua and no dependency on the separate house-ancillaries pack.

**Tech Stack:** Python, existing pack decoder, TSV generators, RPFM MCP, WH3 database tables and localisation.

**Spec:** [2026-10-06-kharkadon-personal-line-design.md](../specs/2026-10-06-kharkadon-personal-line-design.md).

## Global constraints

- Preserve all existing node keys, positions, prerequisites, levels and the exclusive rank-24 choice.
- Preserve the lord trait, faction bundle, items, existing passive and bodyguard unlocks.
- Use `derpy_kharkadon` for the lord; keep `zharrduk` for house keys.
- Aura: 35 metres, self and friendly units, +8 attack, +8 defence, Perfect Vigour, 25 seconds, 120-second cooldown, unlimited uses, melee condition.
- Preserve current pack stats, models, portraits, starting armies, missions and every other lord's rows.
- Read current saved packs; historical hashes and loose staging are not current truth.
- New DB/loc files are generated TSVs imported with RPFM, never text edits to binary fragments.
- No Workshop upload is part of implementation. Distinguish build, local deployment and live testing.
